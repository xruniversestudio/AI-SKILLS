# Copy-paste prompts

Give the user the version in their language. The user pastes these in the **old** account unless stated otherwise.

## 1. Memory, verbatim (old account)

English:

```text
Write out your memories of me verbatim, exactly as they appear in your memory. Put everything in one code block, one entry per line. Do not summarize, group or omit anything. After the block, say whether this is the complete set.
```

Arabic:

```text
اكتب كل ما تتذكره عني حرفياً كما هو مخزّن في ذاكرتك، داخل كتلة كود واحدة، كل معلومة في سطر. لا تلخّص ولا تجمّع ولا تحذف شيئاً. بعد الكتلة، قل لي هل هذه المجموعة كاملة.
```

## 2. Project instructions and files (run inside each project, old account)

English:

```text
For this project, give me: (1) the project's instructions exactly as written, in a code block; (2) the names of all knowledge files; (3) a five-line summary of the project's purpose, status and key decisions so far.
```

Arabic:

```text
لهذا المشروع أعطني: (1) تعليمات المشروع كما هي حرفياً داخل كتلة كود؛ (2) أسماء كل ملفات المعرفة؛ (3) ملخصاً من خمسة أسطر عن هدف المشروع وحالته وأهم القرارات حتى الآن.
```

## 3. Files produced in a conversation (old account, per chat)

English:

```text
List every file you produced in this conversation as a table: file name, type, what it is, and a link if one exists. If you cannot give a link for a file, write "link not recoverable".
```

Arabic:

```text
اسرد كل ملف أنتجته في هذه المحادثة في جدول: اسم الملف، نوعه، ما هو، والرابط إن وُجد. إذا لا يوجد رابط لملف اكتب "الرابط غير قابل للاسترجاع".
```

## 4. Chat digest (old account, per important chat)

```text
Digest this conversation for a handoff. Give: Context (1-2 lines), Decisions, Open items, Files. Keep facts and decisions only; no pleasantries.
```

## 5. Verification (new account, after restore)

English:

```text
What do you know about me, my projects and how I like to work? List it in short lines and say which parts you are unsure about.
```

Arabic:

```text
شو بتعرف عني وعن مشاريعي وطريقتي بالشغل؟ اكتبها بأسطر قصيرة وقل لي أي أجزاء مو متأكد منها.
```

## 6. Opening line for a memory import (new account)

```text
This is my memory from another account. Add this information to your memory.
```
